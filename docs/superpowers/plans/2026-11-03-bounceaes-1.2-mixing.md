# BounceAES Master 1.2 — miksowanie i karty wielokanałowe: plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kilka źródeł z głośnością na jeden cel (AoIP, ASIO, Windows) przez szyny miksu w usłudze oraz osobne pary kanałów kart wielokanałowych Windows.

**Architecture:** Konfiguracja dostaje `mixes` (cel → źródła z dB). Usługa przydziela celom w trybie miksu szyny (nowe pierścienie w pamięci współdzielonej v3), wątek miksera co 1 ms sumuje członków do szyny, a cele czytają szynę jak pojedyncze źródło (`ShmSource::Mix`, `D_mix = max D_src + 96`). Miks jednoźródłowy 0 dB pozostaje połączeniem bezpośrednim. Audio Bridge grupuje cele jednego urządzenia w jeden wielokanałowy strumień WASAPI.

**Tech Stack:** C++20, CMake, doctest, nlohmann/json, cpp-httplib, libsamplerate, WASAPI (bridge), vanilla JS panel.

**Spec:** `docs/superpowers/specs/2026-11-03-bounceaes-mixing-design.md`

## Global Constraints

- Do 32 miksów, do 16 źródeł w miksie, głośność −60…+12 dB krok 0,5 dB, wyciszenie per źródło.
- Miks z dokładnie jednym niewyciszonym źródłem na 0 dB = połączenie bezpośrednie (bit w bit, bez dodatkowego opóźnienia).
- `D_mix = max(D_src członków) + 96` próbek; mikser co 1 ms, bloki po 48 próbek, suma w `double`, zapis z nasyceniem (`from_float`).
- Pamięć współdzielona: `kShmVersion = 3`, nazwa `BounceAESMaster.v3`, magia `0x42414D33` ("BAM3"), 32 pary szyn (64 kanały).
- Identyfikator pary karty: `win-out:<endpoint>` = para 1, `win-out:<endpoint>#N` = para N (N ≥ 2).
- Konfiguracja `"version": 2`, pole `mixes` opcjonalne; wersja produktu 1.2.0.
- Testy i dema wyłącznie na 127.0.0.1; usługę demo uruchamiać tylko z `config.json` sprawdzonym na `interface_ip` i `http_bind` = 127.0.0.1.
- Teksty dla użytkownika po polsku; komentarze w kodzie po angielsku, w stylu otoczenia.
- Po każdym zadaniu: `cmake --build build -j8 && ./build/bam_tests` zielone; MinGW 64 i 32 (`build-win`, `build-win32`) bez ostrzeżeń.

```cpp
// SPDX-License-Identifier: GPL-3.0-or-later
#pragma once
#include <array>
#include <atomic>
#include <cstdint>
#include <memory>
#include <mutex>
#include <vector>

#include "bam/timeline.hpp"

namespace bam {

inline constexpr int kMixBuses = 32;
inline constexpr uint32_t kMixMarginFrames = 96;  // 2 ms: a mix is ready this long after its slowest member

struct MixInput {
  ChannelRing left, right;
  double gain = 1.0;   // linear; 0 = muted
  uint32_t delay = 0;  // D_src of the member
};

struct MixBusPlan {
  int bus = 0;  // 0..kMixBuses-1
  ChannelRing out_left, out_right;
  std::vector<MixInput> inputs;
  uint32_t max_delay = 0;  // max D_src of the inputs
};

// Sums the members of every mix bus onto the bus rings, in 48-frame blocks, up to
// "now - max_delay" of each bus. process() runs on one thread; set_plan() from any thread.
class Mixer {
 public:
  Mixer();
  void set_plan(std::vector<MixBusPlan> plan);
  void process(uint64_t now_s, uint64_t generation);
  uint64_t late() const { return late_.load(std::memory_order_relaxed); }
  float peak_db(int bus, int side) const;

 private:
  struct State {
    bool started = false;
    uint64_t mixed_upto = 0;
  };
  std::mutex plan_mutex_;
  std::shared_ptr<const std::vector<MixBusPlan>> plan_;
  std::array<State, kMixBuses> state_{};
  uint64_t generation_ = 0;
  std::atomic<uint64_t> late_{0};
  std::array<std::atomic<float>, kMixBuses * 2> peak_;
};

}  // namespace bam
```

```cpp
// SPDX-License-Identifier: GPL-3.0-or-later
#include "bam/mixer.hpp"

#include <algorithm>
#include <cmath>

#include "bam/rate_control.hpp"

namespace bam {

namespace {
constexpr uint32_t kBlock = 48;
constexpr uint64_t kRestartFrames = 4800;  // 100 ms off: start over at "now"
}  // namespace

Mixer::Mixer() : plan_(std::make_shared<std::vector<MixBusPlan>>()) {
  for (auto& p : peak_) p.store(-120.0f);
}

void Mixer::set_plan(std::vector<MixBusPlan> plan) {
  auto next = std::make_shared<const std::vector<MixBusPlan>>(std::move(plan));
  std::lock_guard lock(plan_mutex_);
  plan_ = std::move(next);
}

float Mixer::peak_db(int bus, int side) const {
  if (bus < 0 || bus >= kMixBuses) return -120.0f;
  return peak_[bus * 2 + side].load(std::memory_order_relaxed);
}

void Mixer::process(uint64_t now_s, uint64_t generation) {
  std::shared_ptr<const std::vector<MixBusPlan>> plan;
  {
    std::lock_guard lock(plan_mutex_);
    plan = plan_;
  }
  if (generation != generation_) {
    generation_ = generation;
    for (auto& s : state_) s.started = false;
  }
  std::vector<int32_t> in(kBlock), out_l(kBlock), out_r(kBlock);
  std::vector<double> acc_l(kBlock), acc_r(kBlock);
  for (const auto& bus : *plan) {
    if (bus.bus < 0 || bus.bus >= kMixBuses) continue;
    State& st = state_[bus.bus];
    const uint64_t limit = now_s > bus.max_delay ? now_s - bus.max_delay : 0;
    if (!st.started || st.mixed_upto + kRestartFrames < limit || st.mixed_upto > limit + kRestartFrames) {
      st.mixed_upto = limit;
      st.started = true;
    } else if (limit > st.mixed_upto + kMixMarginFrames) {
      late_.fetch_add(1, std::memory_order_relaxed);  // consumers may already have read unmixed frames
    }
    float peak[2] = {0, 0};
    while (st.mixed_upto + kBlock <= limit) {
      std::fill(acc_l.begin(), acc_l.end(), 0.0);
      std::fill(acc_r.begin(), acc_r.end(), 0.0);
      for (const auto& m : bus.inputs) {
        if (m.gain == 0.0) continue;
        m.left.read(st.mixed_upto, in.data(), kBlock);
        for (uint32_t i = 0; i < kBlock; ++i) acc_l[i] += static_cast<double>(in[i]) * m.gain;
        m.right.read(st.mixed_upto, in.data(), kBlock);
        for (uint32_t i = 0; i < kBlock; ++i) acc_r[i] += static_cast<double>(in[i]) * m.gain;
      }
      for (uint32_t i = 0; i < kBlock; ++i) {
        out_l[i] = from_float(static_cast<float>(acc_l[i] / 2147483648.0));
        out_r[i] = from_float(static_cast<float>(acc_r[i] / 2147483648.0));
        // exact for sums that fit: keep integer arithmetic when no clipping happens
        if (std::abs(acc_l[i]) < 2147483392.0) out_l[i] = static_cast<int32_t>(std::lround(acc_l[i]));
        if (std::abs(acc_r[i]) < 2147483392.0) out_r[i] = static_cast<int32_t>(std::lround(acc_r[i]));
        peak[0] = std::max(peak[0], std::abs(to_float(out_l[i])));
        peak[1] = std::max(peak[1], std::abs(to_float(out_r[i])));
      }
      bus.out_left.write(st.mixed_upto, out_l.data(), kBlock);
      bus.out_right.write(st.mixed_upto, out_r.data(), kBlock);
      st.mixed_upto += kBlock;
    }
    for (int c = 0; c < 2; ++c)
      peak_[bus.bus * 2 + c].store(peak[c] > 1e-6f ? 20.0f * std::log10(peak[c]) : -120.0f, std::memory_order_relaxed);
  }
}

}  // namespace bam
```
Note: integer path keeps 24-bit samples bit-exact (low byte stays 0 for sums of left-aligned 24-bit values at 0 dB); clipped sums go through `from_float` saturation. The "0.5 gain" test expects `0x40000000 * 0.5 = 0x20000000` exactly.
